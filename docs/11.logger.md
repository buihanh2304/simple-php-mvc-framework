# Logger

Write application logs to daily files in `system/files/logs/`.

```php
use System\Classes\Logger;

$logger = app(Logger::class);
$logger->info('User {id} logged in', ['id' => 1]);
$logger->error('Payment failed', ['order_id' => 15]);
```

Or use the helper:

```php
logger('User {id} logged in', ['id' => 1]);
logger()->warning('Slow query', ['sql' => $sql, 'ms' => 120]);
```

## Levels

`debug`, `info`, `notice`, `warning`, `error`, `critical`, `alert`, `emergency`

Messages below the configured minimum level are ignored.

## Config

`configs/autoload/system.php`

```php
'log' => [
    'path' => env('LOG_PATH', SYSTEM . 'files' . DS . 'logs'),
    'level' => env('LOG_LEVEL', 'debug'),
],
```

Set `LOG_LEVEL` in `.env` (for example `warning`) to drop noisier messages.

Each day writes to a file named `Y-m-d.log`, for example `2026-09-11.log`.

Scalar values in `{placeholders}` are interpolated into the message. Remaining context is appended as JSON. Pass an `exception` key with a `Throwable` to append the stack trace.
